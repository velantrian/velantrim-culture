# ✧🌿 Velantrim Foundations — Модуль: Групповая психология и фасилитация 🌿✧

Версия: 1.0
Дата: 16.08.2025
Авторский стиль: Velantrim / Qarythus

## 🎯 Цель модуля

Сделать групповую динамику предсказуемой и созидательной: превратить конформизм, деиндивидуацию и эмоциональное «заражение» из рисков в ресурсы общины.

## 📚 Теоретическая опора (кратко)

Конформизм — нормативное и информационное влияние; польза: координация, риск: «спираль молчания».

Деиндивидуация — ослабление личной ответственности в толпе/анонимности; риск: импульсивность; польза при этических рамках: «тёплое самозабвение» (общие ритмы, труд).

Эмоциональное заражение — быстрый перенос аффекта; риск: паника; польза: эмпатия, синхрон.

Дополняющие эффекты: групповая поляризация, диффузия ответственности, пороговые модели участия, SIDE-модель.

## 🧭 Принципы

1. Ясные рамки до эмоций.
2. Роли видимы.
3. Короткие циклы решений.
4. Уважение к несогласию.
5. Честь выше шума.

## 🃏 Карточки ролей (для печати A6)

### 1. Хранитель Ритма

Знак: 🥁
Задача: темп, паузы, «60 секунд тишины».
Фразы: «Замедлимся», «Пауза на дыхание».
Инструменты: метроном/таймер, чаша/колокольчик.

### 2. Адвокат Сомнения

Знак: ❓
Задача: артикулировать риски/альтернативы, снижать поляризацию.
Фразы: «Какие потери, если мы ошибаемся?», «Есть третий путь?».
Инструменты: доска «Две колонки: За / Риски».

### 3. Смотритель Заботы

Знак: 💚
Задача: отслеживать перегрев, усталость, защиту уязвимых.
Фразы: «Сделаем воду-выдох-горизонт», «Кто устал — перерыв».
Инструменты: вода, плед, зона тишины.

### 4. Хронометр

Знак: ⏱️
Задача: регламент, смена тем, «правило одной руки».
Фразы: «Осталась 1 минута», «Следующий говорит».
Инструменты: таймер/песочные часы.

### 5. Летописец

Знак: 🖋️
Задача: итоги, решения, ответственные и сроки.
Фразы: «Фиксирую формулировку», «Кто ответственный?».
Инструменты: блокнот/планшет, шаблон итогов.

### 6. Медиатор (по необходимости)

Знак: 🕊️
Задача: разрядка напряжения, переформулировка, техника NVC.
Фразы: «Слышу, что для тебя важно…», «Как решение устроит обоих?».
Инструменты: карточки NVC.

## 🧾 Чек-листы (A4 / A5)

### A. Перед встречей — подготовка

- [ ] Цель и ожидаемый результат объявлены одним предложением.
- [ ] Роли назначены и видимы (бейджи/таблички).
- [ ] Пространство: круг, вода, тихая зона, вентиляция.
- [ ] Правила на виду: нулевая травля, «право вежливого НЕТ», тайминг.
- [ ] Инструменты: таймер, маркеры, предмет-символ речи, карточки.

### B. Во время — протокол

- [ ] «60 секунд тишины» в начале.
- [ ] Ритуал «Семь вдохов» (вдох 4, выдох 6–8) — 2 минуты.
- [ ] «Правило одной руки» — говорит держатель символа.
- [ ] «Две колонки»: За и Риски фиксируются попеременно.
- [ ] «Ступени согласия» ✋1–5 перед финальным решением.
- [ ] «Охлаждение» при перегреве: вода → выдох → горизонт.

### C. После — закрепление

- [ ] Итоги (что решено, кто делает, сроки) разосланы ≤24 ч.
- [ ] Ретроспектива: что помогло единству? что грозило поляризацией?
- [ ] Метрики обновлены (см. ниже).

## 🧪 Практики (короткие форматы)

1. **«Семь вдохов» (2 мин.)** — Ведущий: «Вдох на 4, выдох на 6–8. На последнем — мягкая улыбка глазами».
2. **«Пол-круга голоса» (3–5 мин.)** — Половина круга произносит слова-ценности (честь, забота, правда), другая половина повторяет.
3. **«Общий ритм» (3–5 мин.)** — Простые хлопки/удары в унисоне → тихое завершение → 30 сек тишины.
4. **«Треугольник стабилизации» (30–60 сек.)** — Вода → медленный выдох → взгляд в горизонт.

## 🧩 Сценарии (готовые шаблоны)

### S1. Молодёжный круг (высокая возбудимость)

1. «Семь вдохов» → игра на синхронизацию внимания (3–4 мин.).
2. Сбор тем карточками.
3. Дискуссия по теме 5–7 мин. с Адвокатом Сомнения.
4. Ступени согласия ✋1–5.
5. Завершение: «одна мысль — один жест благодарности».

### S2. Внезапная паника/тревожная новость

1. Сигнал ведущего: «Стоп — вода — выдох — горизонт».
2. Распределение ролей: дети/пожилые, связь, сбор фактов.
3. Сводка каждые 3 минуты; решения — только после единой картины.

### S3. Онлайн-пространство Velantrim

Реальные имена по умолчанию, «медленный режим», ограничение длины реплик.
Видимые «ступени согласия», кнопка «охладить тред», ротация модерации.
Обязательная роль Адвоката Сомнения в горячих темах.

## 📏 Метрики сообщества

- Пульс сообщества (еженедельно): спокойствие/доверие/ясность (1–5).
- Индекс участия: ≥60% присутствующих высказались.
- Баланс решений: не менее 1:1 по пунктам «За/Риски».
- Краткая ретро: 3 вопроса — «что объединило», «что разделяло», «чем гордимся».

> Примечание: в проектах здравоохранения параллельно можно отслеживать PHQ-9/GAD-7 индивидуально; групповые индексы дополняют картину.

## 🧰 Матрица рисков (триггеры → ответ)

- Шум/перебивание → Хронометр: «правило одной руки», предмет-символ.
- Эскалация эмоций → Смотритель Заботы: «охлаждение», пауза 2 мин.
- Застывшее молчание → Ведущий: «круг из одного предложения».
- Групповая поляризация → Адвокат Сомнения: «две колонки», поиск третьего пути.

## 🖼️ Мини-плакат (A4) — «Сигналы руками»

- Ладонь вниз — «замедляемся»
- Ладонь на сердце — «эмпатия/согласие с чувствами»
- Два пальца вверх ✌️ — «прояснить факт»
- Кулак к груди — «перерыв/вода»
- Поднятая ладонь ✋1–5 — «ступени согласия» (1 — нет; 3 — могу жить; 5 — да с радостью)

(Распечатать крупно, повесить в зоне видимости.)

## 📜 Политика несогласия (короткая)

- Несогласие — ресурс. Инакомыслие защищает от ошибок толпы.
- Право «вежливого НЕТ». Без объяснений; группа уважает.
- Критика = предложение. Если критикуешь — предложи альтернативу или критерий.
